# DevNest 数据模型

> 版本:v1.1  日期:2026-09-01  作者:Ajiejiejie

## 1. 三类数据澄清

DevNest 里有三类数据,角色完全不同,必须区分:

| 类别 | 例子 | 归属 | 存储 | 连接方式 |
|---|---|---|---|---|
| **A 工具自身配置** | SSH 跳板、终端会话、数据源连接信息、HTTP 模板、AI 配置 | DevNest 自己 | 配置库(H2/MySQL) | 固定 DataSource |
| **B 工具自身日志** | SQL 执行日志、SFTP 操作日志 | DevNest 自己 | 配置库(同库)或 Logback 文件 | 固定 DataSource |
| **C 用户业务数据** | 用户业务 MySQL 库表、Redis key、内网接口 | **不属于 DevNest** | DevNest 不存,只做客户端连接 | 运行时动态 DataSource |

**关键**:三期"MySQL 可视化"连的是 C 类用户业务库,**不是**配置库。配置库和业务数据源是不同连接池、不同事务、不同生命周期,代码层隔离。

## 2. 配置库选型

| profile | 数据库 | 用途 | 启动参数 |
|---|---|---|---|
| `dev`(默认) | H2 文件(MySQL 模式) | 开发调试,免安装秒级启动 | `--spring.profiles.active=dev` |
| `prod` | MySQL 8 | 自用日常,可用任意客户端查配置/日志 | `--spring.profiles.active=prod` |

H2 用 MySQL 兼容模式,Flyway 脚本 H2/MySQL 共用。

## 3. 表清单

| 表 | 模块 | 用途 | 敏感字段 |
|---|---|---|---|
| `ssh_bastion` | SSH 隧道(一期) | SSH 跳板配置 | password(AES) |
| `ssh_port_mapping` | SSH 隧道(一期) | 端口映射模板 | - |
| `remote_console_session` | SSH 控制台(二期) | 终端/SFTP 会话配置 | auth_credential(AES) |
| `sftp_operation_log` | SSH 控制台(二期) | SFTP 操作日志 | - |
| `data_source_db` | 数据库模块(三期) | 数据库数据源 | password(AES) |
| `sql_execute_log` | 数据库模块(三期) | SQL 执行日志 | - |
| `data_source_redis` | Redis 模块(四期) | Redis 数据源 | password(AES) |
| `http_request_template` | HTTP 模块(五期) | 请求模板 | - |
| `system_ai_config` | AI 模块(六期) | 全局 AI 配置 | api_key(AES) |

字段统一含 `id`(BIGINT 自增/雪花)、`create_time`、`update_time`。

## 4. 一期 SSH 模块 DDL(MySQL 方言,H2 兼容)

### 4.1 ssh_bastion(SSH 跳板配置表)

```sql
CREATE TABLE ssh_bastion (
    id              BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    name            VARCHAR(64)  NOT NULL COMMENT '跳板名称(用户可读)',
    ssh_host        VARCHAR(128) NOT NULL COMMENT 'SSH 主机地址',
    ssh_port        INT          NOT NULL DEFAULT 22 COMMENT 'SSH 端口',
    ssh_user        VARCHAR(64)  NOT NULL COMMENT '登录用户名',
    ssh_password    VARCHAR(512) NOT NULL COMMENT '登录密码(AES 加密密文,IV+密文 base64)',
    remark          VARCHAR(255) NULL COMMENT '备注',
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_name (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SSH 跳板配置';
```

### 4.2 ssh_port_mapping(端口映射模板表)

```sql
CREATE TABLE ssh_port_mapping (
    id                  BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    bastion_id          BIGINT       NOT NULL COMMENT '归属跳板 ID',
    remote_host         VARCHAR(128) NOT NULL COMMENT '远端内网 IP',
    remote_port         INT          NOT NULL COMMENT '远端内网端口',
    preferred_local_port INT         NULL COMMENT '期望本地端口(可空,空则自动分配)',
    allocated_local_port INT         NULL COMMENT '运行时实际分配端口(运行中才有值)',
    label               VARCHAR(64)  NULL COMMENT '功能备注(如:测试库/回归库/对象云)',
    create_time         DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time         DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_bastion (bastion_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SSH 端口映射模板';
```

**字段设计要点**:
- 补 `preferred_local_port`:用户期望端口(可空),解决"每次启动重新分配导致数据源 HOST/PORT 失效"问题
- 补 `allocated_local_port`:运行时记录实际端口,前端展示用,停止后清空
- 补 `label`:对应原型代码注释(测试/回归/对象云/新能运),便于识别

## 5. 二期+ 表 DDL(预留,后续迭代实现)

### 5.1 remote_console_session(远程控制台会话表,二期)

```sql
CREATE TABLE remote_console_session (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    name            VARCHAR(64)  NOT NULL COMMENT '会话名称',
    bastion_id      BIGINT       NOT NULL COMMENT '绑定跳板 ID',
    session_type    VARCHAR(8)   NOT NULL COMMENT 'SHELL/SFTP',
    remote_host     VARCHAR(128) NULL COMMENT '远端主机(空=直接用跳板机 shell)',
    remote_port     INT          NULL DEFAULT 22 COMMENT '远端端口',
    username        VARCHAR(64)  NULL COMMENT '空=用跳板账号',
    auth_credential VARCHAR(512) NULL COMMENT '登录密码/密钥(AES,空=用跳板凭证)',
    encoding        VARCHAR(16)  NOT NULL DEFAULT 'UTF-8' COMMENT '终端编码',
    remark          VARCHAR(255) NULL,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_bastion (bastion_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='远程控制台会话配置';
```

**要点**:`remote_host` 为空表示直接对跳板机开 shell(ChannelShell on bastion),非空表示通过跳板跳转登录内网其他主机;`auth_credential` 为空表示复用跳板凭证,实现"一次配置,多会话复用"。

### 5.2 sftp_operation_log(SFTP 操作日志表,二期)

```sql
CREATE TABLE sftp_operation_log (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    session_id      BIGINT       NULL COMMENT '关联会话 ID(可空,临时会话也记)',
    bastion_id      BIGINT       NOT NULL,
    op_type         VARCHAR(16)  NOT NULL COMMENT 'UPLOAD/DOWNLOAD/DELETE/RENAME',
    remote_path     VARCHAR(512) NOT NULL,
    local_path      VARCHAR(512) NULL,
    status          VARCHAR(16)  NOT NULL COMMENT 'SUCCESS/FAIL',
    cost_ms         INT          NULL,
    error_msg       TEXT         NULL,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_session_time (session_id, create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='SFTP 操作日志';
```

### 5.3 data_source_db(数据库数据源表,三期)

```sql
CREATE TABLE data_source_db (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    name            VARCHAR(64)  NOT NULL COMMENT '连接名称',
    db_type         VARCHAR(16)  NOT NULL COMMENT '类型:MYSQL/DM',
    connect_mode    VARCHAR(16)  NOT NULL COMMENT '连接模式:DIRECT 直连/TUNNEL 隧道',
    host            VARCHAR(128) NULL COMMENT '直连模式:主机;隧道模式 NULL',
    port            INT          NULL COMMENT '直连模式:端口;隧道模式 NULL',
    tunnel_id       BIGINT       NULL COMMENT '隧道模式:绑定 ssh_bastion.id',
    remote_host     VARCHAR(128) NULL COMMENT '隧道模式:远端内网 IP',
    remote_port     INT          NULL COMMENT '隧道模式:远端端口',
    db_name         VARCHAR(128) NOT NULL COMMENT '库名',
    username        VARCHAR(64)  NOT NULL,
    password        VARCHAR(512) NOT NULL COMMENT 'AES 加密',
    remark          VARCHAR(255) NULL,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_tunnel (tunnel_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**要点**:`connect_mode` + 拆分直连/隧道两套字段,避免用一个 host/port 承载两种语义(原需求缺口)。

### 5.4 data_source_redis(Redis 数据源表,四期)

```sql
CREATE TABLE data_source_redis (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    name            VARCHAR(64)  NOT NULL,
    connect_mode    VARCHAR(16)  NOT NULL COMMENT 'DIRECT/TUNNEL',
    host            VARCHAR(128) NULL,
    port            INT          NULL,
    tunnel_id       BIGINT       NULL,
    remote_host     VARCHAR(128) NULL,
    remote_port     INT          NULL,
    password        VARCHAR(512) NULL COMMENT 'AES 加密,可空',
    db_index        INT          NOT NULL DEFAULT 0,
    remark          VARCHAR(255) NULL,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    KEY idx_tunnel (tunnel_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5.5 http_request_template(HTTP 请求模板表,五期)

```sql
CREATE TABLE http_request_template (

    headers         TEXT         NULL COMMENT 'JSON 存储',
    body            TEXT         NULL,
    remark          VARCHAR(255) NULL,
    create_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

```

### 5.6 system_ai_config(全局 AI 配置表,六期)

```sql
CREATE TABLE system_ai_config (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    enabled         BOOLEAN      NOT NULL DEFAULT FALSE COMMENT 'AI 全局开关',
    base_url        VARCHAR(255) NOT NULL COMMENT 'OpenAI 兼容接口地址',

    model           VARCHAR(64)  NOT NULL,

    update_time     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
```

```sql
CREATE TABLE sql_execute_log (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    data_source_id  BIGINT       NOT NULL,
```

## 6. 加密方案

### 6.1 字段标识

| 表 | 字段 | 算法 |
|---|---|---|
| ssh_bastion | ssh_password | AES-256-GCM |
| remote_console_session | auth_credential | AES-256-GCM |
| data_source_db | password | AES-256-GCM |
| data_source_redis | password | AES-256-GCM |
| system_ai_config | api_key | AES-256-GCM |

### 6.2 密钥管理

- **主密钥(MK)**:首次启动生成 32 字节随机,存于 `~/.devnest/master.key` 文件
- **二级密钥**:用机器 ID(MAC + CPU 序列 + 用户名)PBKDF2 派生 32 字节,加密 MK 文件
- **运行时**:启动加载 MK 到内存,加解密敏感字段
- **换机子**:MK 文件无效,需重新输入(自用工具可接受;或导出/导入 MK 文件 + 用户口令)

### 6.3 密文格式

`base64(IV(12B) || ciphertext || tag(16B))`,存储为 VARCHAR(512) 足够。

### 6.4 前端脱敏

密码字段返回 `********`(8 个星号),不返回明文。编辑时密码字段留空表示不改,填值表示改密。
