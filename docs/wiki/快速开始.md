# 快速开始

## 0. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | **21（必须）** | 后端要求 21。本机默认若是 1.8，**不要裸跑 `mvn`** |
| Maven | 3.9+ | 跟随 `backend/pom.xml` |
| Node.js | 20+（CI 用 24） | 仅前端需要 |
| Rust | stable + `x86_64-pc-windows-msvc` | 仅打安装包需要（Tauri） |
| Docker | 可选 | 跑 Testcontainers 集成测试需要；没有时相关用例显式 skip |

> 省事就用仓库自带脚本 `scripts/start-backend.ps1`：它会把控制台切成 UTF-8 并自动定位 JDK 21。

---

## 1. 启动后端

```powershell
cd backend/devnest-boot
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

或等价的一键脚本：

```powershell
.\scripts\start-backend.ps1
```

- 默认绑定 `127.0.0.1:38080`
- H2 文件库落在 `<工作目录>/data/devnest-dev.mv.db`，重启数据不丢
- 表结构由 **Flyway** 迁移管理（`backend/devnest-boot/src/main/resources/db/migration`），JPA 仅 `validate`
- 接口文档见 [docs/API.md](https://github.com/surperjie/devnest/blob/main/docs/API.md)

### 达梦（DM）驱动不在 Maven Central

仓库内置 `backend/lib/DmJdbcDriver18-8.1.3.140.jar`。若本地 `~/.m2` 中没有 `com.dameng:DmJdbcDriver18`，构建会失败；手动装一次即可（CI 每次构建都会做这一步）：

```powershell
cd backend
mvn install:install-file `
  "-Dfile=lib/DmJdbcDriver18-8.1.3.140.jar" `
  "-DgroupId=com.dameng" `
  "-DartifactId=DmJdbcDriver18" `
  "-Dversion=8.1.3.140" `
  "-Dpackaging=jar" `
  -B -q
```

## 2. 启动前端

```powershell
cd frontend-ui
npm install
npm run tauri:dev
```

- dev server 端口 `1420`
- 后端 CORS 已放行 `127.0.0.1:1420` / `localhost:1420` / `tauri://localhost` / `http://tauri.localhost`
- 前端 axios 直连 `http://127.0.0.1:38080/api`（见 `frontend-ui/src/api/http.js`）

---

## 3. 本地打安装包

```powershell
.\build-app.ps1                 # Maven 打包 jar → 复制到 resources → jlink 生成 jre21 → tauri build
.\build-app.ps1 -SkipBackend    # 后端 jar 无变动时跳过 Maven
```

产物：`frontend-ui/src-tauri/target/release/bundle/`（NSIS exe / MSI）。

> 本地产物**未做代码签名**，安装时可能触发 SmartScreen 警告。

不想在本地等 10~20 分钟，可以让 CI 帮你打：见 [CI 与发布](CI与发布)。

## 4. 安装后的运行方式（零配置）

双击即用：不需要装数据库，不需要改任何配置。

| 内容 | 位置 |
|---|---|
| 配置库 | `%LOCALAPPDATA%\DevNest\data\devnest.mv.db` |
| 流水线工作区 | `%LOCALAPPDATA%\DevNest\data\pipeline\` |
| 加密主密钥 | `%USERPROFILE%\.devnest\master.key`（首次启动自动生成） |
| 应用日志 | `%TEMP%\devnest-app.log` |
| 后端日志 | `%TEMP%\devnest-backend.log`（UTF-8） |
| 单实例锁 | `%LOCALAPPDATA%\DevNest\app.lock` |

几个设计上的"不静默"：

- 关窗口时先请求后端优雅退出（`POST /actuator/shutdown`），超时才强杀 —— 避免 H2 数据损坏。
- 重复启动直接退出（单实例锁），不会出现两个实例互抢后端。
- `38080` 被占用会**弹窗明确提示**，而不是静默失败。
- 后端起不来时，弹窗附带 `%TEMP%\devnest-backend.log` 的日志尾部，便于定位。
